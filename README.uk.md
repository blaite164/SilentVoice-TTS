**Не можеш або не хочеш говорити в мікрофон? Просто друкуй, а SilentVoice озвучить усе за тебе — у дзвінках, іграх чи на стрімі.**

Програма створена передусім для **німих людей**, тих, кому складно говорити голосом, вітуберів та геймерів, які віддають перевагу текстовому спілкуванню. **SilentVoice** працює поверх будь-яких ігор, не забирає фокус вікна та не ламає ігровий процес.

## ✨ Основні можливості

### 🗣️ Голос та Озвучка
- **Встановлення локальних TTS в один клік:** Завантаження офлайн-моделей прямо з програми з прогрес-баром, автоматичним підбором дзеркал та підтримкою проксі.
  - **Підбірка під кожну мову:** Для української та російської мов доступно по **5 локальних TTS** (3 швидкі моделі на CPU з попереднім прослуховуванням голосів + 2 моделі на GPU з клонуванням голосу), для англійської та інших мов — **4 моделі**.
  - **Клонування голосу та OpenVoice v2:** Клонування на GPU із готовими збірками голосів (UK / RU / EN) та підтримкою власних аудіофайлів, а також передача тембру через **OpenVoice v2** для надання індивідуальності базовим TTS.
- **Хмарні TTS через API (6+ сервісів):** Встановлення **Edge TTS** в одну кнопку, підключення 6+ онлайн-сервісів із вбудованими покроковими гайдами з отримання API-ключів.
- **Резервування та DSP-обробка:** Налаштування основного та запасного TTS (автоматичне перемикання у разі збою) і накладання звукових **DSP-фільтрів**.
- **Розумне кешування та історія:** Зберігає до ~1000 останніх озвучок для миттєвого відтворення без повторної генерації, а фрази, що часто повторюються, зберігає назавжди.
- **Зручна фільтрація:** Швидкий вибір мови TTS та фільтр голосів за статтю прямо в бічному меню.

### 🧠 AI Орфографія
- **Автоматичне виправлення помилок:** Перед відправкою тексту в TTS мовна модель миттєво виправляє одруки, граматику та розставляє розділові знаки.
- **Хмарні та локальні LLM:** Підтримка **7+ хмарних AI-сервісів** (із гайдами) або повністю локальна робота через **Ollama**, **LM Studio** чи **llama.cpp**.
- **Гнучке налаштування:** Можливість задати основну та запасну LLM і відредагувати системний промпт під свій стиль спілкування.

### 💬 Озвучка чату Twitch
- **Підключення за 3 кліки:** Зрозуміла інструкція та швидка авторизація за токеном.
- **Гнучкі команди та голоси:** Налаштовуйте тригер-команди (наприклад, `!t`), призначайте окремий TTS і голос під кожну команду, вмикайте озвучку власних повідомлень із чату та переглядайте історію.
- **Розділення звуку через VBAN:** Можливість окремо маршрутизувати озвучку свого тексту та повідомлень глядачів.

### ⚡ Швидкі фрази та Саундпад
- **Гарячі клавіші на будь-яку фразу:** Призначайте текстові фрази на клавіші, заздалегідь записуйте їх у `.wav` для миттєвого відтворення або додавайте власні звуки у форматі `.mp3`.
- **Історія сказаного:** Швидкий повтор будь-якої раніше озвученої фрази, додавання в **Швидкі фрази** прямо зі списку історії або збереження в окремий аудіофайл.

### ⌨️ Кнопки та Ввід (Безпечно для ігор)
- **Непомітний оверлей поверх ігор:** Натисніть <kbd>Ctrl</kbd> + <kbd>Space</kbd> (налаштовується) і просто друкуйте — без рамок, без втрати фокусу вікна та без згортання гри.
- **Режим спілкування:** Після натискання <kbd>Enter</kbd> та озвучки фразу можна одразу друкувати наступну, не натискаючи гарячу клавішу повторно (за бажанням вмикається у налаштуваннях або по <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Space</kbd>).
- **Звукові сигнали:** Акуратні звукові підказки початку та завершення вводу з регулюванням гучності (`0–200%`) і кнопкою перевірки.
- **Ігровий режим (миттєва пауза та збереження тексту):** Автоматично розпізнає запущену гру (у браузері, плеєрах чи Discord не втручається) та швидко вмикається/вимикається хоткеєм <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>G</kbd>. Якщо в бою натиснути ЛКМ/ПКМ або різко смикнути мишею, набір миттєво зупиниться й поверне керування персонажем, а недописаний текст збережеться на **20 секунд** (час налаштовується).

### 🖥️ Текст на екран / Чат
- **Кілька режимів відображення:** Мінімалістичний прозорий текст на екрані з ледь помітним фіолетовим овалом, текст на темній плашці з рамкою або **масштабоване багаторядкове активне вікно вводу** зі збереженням розмірів і компактними кнопками «Повтор», «Стоп» та «Озвучити».
- **Повна кастомізація та чернетка при закритті:** Галочка вільного **перетягування мишкою** (працює для чистого тексту, плашки й активного вікна), налаштування кольору, обводки, кнопка попереднього перегляду, перемикач **приховування від OBS** та **збереження чернетки при випадковому закритті** (**5 с** за замовчуванням, час налаштовується).
- **Дублювання у чат Twitch:** Автоматична відправка озвучених фраз у чат вашого стріму для живішого спілкування з глядачами.

### 🎬 Субтитри OBS із ліпсінгом
- **Підключення через Browser Source:** Просте налаштування виводу субтитрів в OBS через локальний порт.
- **Анімація з ліпсінгом:** Базова анімація появи по літерах автоматично підлаштовує швидкість під тривалість озвучки TTS.
- **Велика бібліотека ефектів:** Комбінування анімацій появи та утримання тексту, 4 стилі миготливого курсора, режим друку в реальному часі та доступ до папки з `index.html` і `style.css` для власних стилів.
- **Візуальний редактор у браузері:** Вбудована вебсторінка для зручного підбору анімацій, миттєвого тестування та збереження налаштувань назад у програму.

### 🔊 Звук та система
- **Встановлення компонентів в один клік:** Інсталяція **Virtual Audio Cable** та **FFmpeg** безпосередньо з інтерфейсу.
- **3-канальний мікшер гучності та гаряче підключення навушників:** Окремі повзунки для виводу у віртуальний кабель (Discord, ігри, OBS), прослуховування у власних навушниках (при підключенні чи відключенні навушників навіть під час озвучки звук автоматично перемикається наживо) та **підмішування мікрофона** (одночасна передача вашого голосу та озвучки в один канал).
- **Передача звуку по мережі (VBAN):** Вивід озвучки на другий ПК для стрімінгу.
- **Доступність та зручність:** Автовизначення мови системи; якщо мова ще не підтримується, програма перекладає вікно привітання та пропонує в один клік перекласти весь інтерфейс через AI або додати власний файл локалізації. Скрізь присутні кнопки підказок `!`, спливаючі пояснення, керування з трею, автозапуск із Windows та вибірковий експорт/імпорт налаштувань.

## 🚀 Швидкий старт

1. **Встановлення:** Запустіть інсталятор SilentVoice та відкрийте програму (при першому запуску з'явиться підказка з 3 простих кроків).
2. **Вибір голосу:** У розділі **«Голос та Озвучка»** завантажте локальний TTS або **Edge TTS** в один клік та оберіть голос.
3. **Налаштування звуку:** У розділі **«Звук та система»** встановіть **Virtual Audio Cable**, оберіть його як мікрофон у Discord чи грі, натисніть <kbd>Ctrl</kbd> + <kbd>Space</kbd>, введіть текст і натисніть <kbd>Enter</kbd>!

## 💡 Історія створення SilentVoice

Ідея програми народилася ще за студентських років під час перегляду вітуберських подкастів, де одна з учасниць — німа стрімерка — ділилася, наскільки складно знайти зручний та доступний інструмент для живого спілкування текстом. Згодом, коли до знайомого стрімера звернулася німа глядачка з проханням зробити для неї програму, яка б говорила замість неї, стало зрозуміло: потрібне не складне вузькоспеціалізоване рішення, а максимально проста, зрозуміла та дружня програма для будь-якої людини.

Так з'явився **SilentVoice** — мультимовний інструмент, створений із турботою про доступність, щоб кожен, хто не може або не хоче говорити вголос, міг вільно спілкуватися в іграх, дзвінках і на стрімах.
